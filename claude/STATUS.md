No selection by the present data, effect size, direction, marker specificity, or overlap with the original lists. Use case-insensitive exact symbol matches in the retained rat data, documenting unmatched entries. This is a same-symbol mapping, not a formal orthology analysis. Use unshrunken Wald statistics, one record per symbol with largest absolute statistic and Ensembl ID as deterministic tiebreaker, min size four, seed 20261116. Save full memberships before running.
